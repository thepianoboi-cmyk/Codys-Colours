# Codys Colours v1.0.1

Public-safe Mac release with the Codys Colours Free Use and Attribution License.

- Adobe Illustrator and Adobe Photoshop CEP panel.
- Generic starter colour library.
- CSV and JSON import for authorised local colour libraries.
- Search, exact/close filters, colour comparison, conversion, image extraction, palettes, favourites, recents, and pattern history.
- Illustrator actions for apply, swatch, and centre-view colour square.
- Photoshop actions for foreground colour and swatch workflow.
- Local-only privacy position.
- Free personal and commercial use, with attribution required for commercial
  public use.
- No resale, rebranding, mirroring, marketplace reposting, or standalone
  redistribution without written permission.
