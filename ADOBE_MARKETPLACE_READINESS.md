# Public Release Safety Checklist

This repository is prepared as a public-safe build of Codys Colours.

## Completed

- No bundled commercial third-party colour guide database.
- No source PDFs, scraped data, private exports, or internal source files.
- Generic starter colours only.
- CSV and JSON import for user-authorised colour libraries.
- Public-facing README, privacy note, terms, and release notes.
- Mac-only Adobe Illustrator and Photoshop CEP support clearly stated.

## Before Any Marketplace Submission

- Confirm the package format still matches the marketplace requirements.
- Use screenshots from this public build only.
- Avoid using third-party colour-standard brand names in listing metadata unless written rights are confirmed.
- Confirm support email, developer identity, and privacy policy URL are ready.
- Re-test install on a clean Mac profile.

## Distribution Recommendation

For this free release, use GitHub Releases and GitHub Pages first. It is faster, free, and does not require marketplace review.
