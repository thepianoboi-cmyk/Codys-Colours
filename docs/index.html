Codys Colours

A free Mac colour workflow panel for Adobe Illustrator and Adobe Photoshop. Search, compare, convert, extract, favourite, and apply colours from libraries you import locally.

Install

1. DownloadGet the latest Mac release ZIP from GitHub Releases.
2. Run InstallerDouble-click Install Codys Colours.command. If macOS blocks it, right-click and choose Open.
3. Open PanelRestart Adobe, then use Window > Extensions (Legacy) > Codys Colours.

Import Your Colours

The public build includes only generic starter colours. Use the panel's Import button to load CSV or JSON libraries that you are authorised to use.

Recommended CSV columns: Name, Hex, R, G, B, C, M, Y, K, Lab, Source, Suffix, Alias.

Privacy

Imported libraries, favourites, palettes, recents, and pattern history stay locally in the panel's browser storage.
