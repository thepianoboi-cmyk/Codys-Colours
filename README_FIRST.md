# Read Me First

Codys Colours is a free Mac-only colour workflow panel for Adobe Illustrator and Adobe Photoshop.

## Install

1. Double-click `Install Codys Colours.command`.
2. Restart Illustrator or Photoshop.
3. Open `Window > Extensions (Legacy) > Codys Colours`.
4. Use `Import` in the panel to load your own authorised CSV or JSON colour library.

## Important

The public build includes only generic starter colours. It does not include any commercial third-party colour guide database. Only import colour data that you have permission to use.

Codys Colours is free to use for personal and commercial work, but it cannot be
resold, rebranded, mirrored, or redistributed as someone else's product. Keep
the Codys Colours name and licence with the plugin.

## CSV Format

Best columns:

```text
Name,Hex,R,G,B,C,M,Y,K,Lab,Source,Suffix,Alias
```

Minimum columns:

```text
Name,Hex
```
